# SatQuery AI

A query-driven satellite image analysis assistant. Users upload satellite images, ask questions in natural language, and receive answers backed by visual evidence, confidence scores, and an auditable execution trace.

**Status**: Project scaffolding initialized. Application features not yet implemented.

## Tech Stack

- **Backend**: FastAPI, SQLAlchemy, PostgreSQL
- **Frontend**: React (pending)

## Setup

```bash
cd backend
python -m venv venv
venv\Scripts\activate      # Windows
pip install -r requirements.txt
uvicorn app.main:app --reload
```
